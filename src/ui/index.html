Modos de Exibição

O OpenCrosshairQ funciona como uma janela de sobreposição transparente (desktop overlay). Jogos em modo tela cheia exclusiva (Exclusive Fullscreen) cobrem janelas normais do Windows; configure o jogo como Janela Sem Bordas (Borderless Windowed) para visualizar a mira. Por ser uma sobreposição externa e não injetar código na memória do jogo, não é detectada como cheat nem interfere com softwares anti-cheat.

Gravação / Streaming

Servidor HTTP local que expõe o estado atual da mira para sobreposições de terceiros (OBS, XSplit e similares).

Servidor HTTP local
Inicia um servidor em 127.0.0.1 na porta 24164. A detecção automática de OBS/XSplit não está implementada; conecte a URL manualmente na fonte do navegador.
